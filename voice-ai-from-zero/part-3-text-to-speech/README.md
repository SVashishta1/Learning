# Part 3 · Text to speech

Now your computer talks back, from robotic to remarkably human, all offline.

| # | Project | Voice quality | What you'll have |
|---|---------|---------------|------------------|
| 09 | [Your computer speaks](09-your-computer-speaks) | 🤖 robotic | instant speech with the voices built into your computer |
| 10 | [Natural voices with Piper](10-natural-voices-with-piper) | 🙂 natural | a fast neural voice, 40+ languages |
| 11 | [Studio-quality voices with Kokoro](11-studio-quality-voices-with-kokoro) | 😍 very natural | 50+ voices you can even mix together |
| 12 | [Speech in the browser](12-speech-in-the-browser) | 🤖 → 😍 | the browser's own voices, then Kokoro running inside the page |

Install once: `pip install pyttsx3 piper-tts kokoro-onnx soundfile sounddevice numpy`
(Linux only: `sudo apt install espeak-ng` for project 09.)
