# Learning

A complete, self-paced path from "I've never written code" to building and deploying AI applications. Every lesson is a small, working project with a README that explains what you're building, how to run it, what you should see, how the code works, how to fix common problems, exercises with solutions, and a self-check quiz.

## Where to start
1. **[ai-from-zero/00-start-here](ai-from-zero/00-start-here)**: install Python and an editor, and run your first file (30 min).
2. Follow the courses in this order (the [learning roadmap](https://claude.ai/artifact/Uc9PDCpQDfCrUvK6BAUbNs) tracks your progress and shows the same order as 8 phases):

| # | Course | What's inside | Time at ~1 h/day |
|---|--------|---------------|------------------|
| 1 | [ai-from-zero](ai-from-zero) | **Start here.** 33 beginner lessons, no experience needed: APIs, machine learning, neural networks, chatbots, RAG and vector databases, AI agents and teams | 6–8 weeks |
| 2 | [voice-ai-from-zero](voice-ai-from-zero) | 22 lessons on local, open-source voice AI: Whisper (also in the browser), Piper, Kokoro, voice detection, who-spoke-when, real-time assistants, voice cloning, a private meeting assistant. Start after AI from Zero Part 4 | 4–5 weeks |
| 3 | [ai-engineer-journey](ai-engineer-journey) | 52 deeper projects with tests: auth and deployment, backprop by hand, classic ML, computer vision, a GPT from scratch, LoRA, RAG evaluation, production apps, multi-agent systems and MCP | 3–4 months |
| ★ | [aws-ai-practitioner](aws-ai-practitioner) | Optional: AWS AIF-C01 exam trainer (flashcards, quizzes, mock exams). Best after AI from Zero Part 6 | 2–3 weeks |

## What you need
- A laptop (Windows, Mac or Linux) with 8 GB of RAM; no GPU required.
- Free: everything except the Claude-powered lessons (AI from Zero Parts 4–6 and some Journey projects), which need an Anthropic API key; a few dollars of credit covers them. The voice course is 100% free and offline.
