# Learning

A complete, self-paced path from "I've never written code" to building and deploying AI applications. Every lesson is a small, working project with a README that explains what you're building, how to run it, what you should see, how the code works, how to fix common problems, exercises with solutions, and a self-check quiz.

## Where to start
1. **[ai-from-zero/00-start-here](ai-from-zero/00-start-here)**: install Python and an editor, and run your first file (30 min).
2. Follow the courses in this order (the [learning roadmap](https://claude.ai/artifact/Uc9PDCpQDfCrUvK6BAUbNs) tracks your progress and shows the same order):

| # | Course | What's inside | Time at ~1 h/day |
|---|--------|---------------|------------------|
| 1 | [ai-from-zero](ai-from-zero) | **Start here.** 33 beginner lessons, no experience needed: APIs, machine learning, neural networks, chatbots, RAG and vector databases, AI agents and teams | 6–8 weeks |
| 2 | [linux-from-zero](linux-from-zero) | Guide: the best free Linux and shell resources (GitHub, docs, YouTube), in order, with a "done when" check per topic. Do alongside course 1 | 2–3 weeks |

## What you need
- A laptop (Windows, Mac or Linux) with 8 GB of RAM; no GPU required.
- Free: everything except the Claude-powered lessons (AI from Zero Parts 4–6 and some Journey projects), which need an Anthropic API key; a few dollars of credit covers them. The voice, on-device and LLM-from-scratch courses run free on your laptop (open models via Ollama).
