# Level 3 · Classic machine learning: sorting toys into groups

Before deep learning, there's a toolbox of fast, explainable models that still power most business ML: credit scores, churn, fraud, pricing. They train in seconds on a laptop, and you can explain every decision. An AI engineer who knows *when a simple model is enough* saves companies a fortune.

In this level you'll predict numbers (regression), sort things into categories (classification), find groups nobody labelled (clustering), learn how scores can lie (evaluation), and finally ship a model behind an API the way real companies do.

| # | Project | Model | You'll understand | Time |
|---|---------|-------|-------------------|------|
| 3.1 | [House price predictor](01-house-price-predictor-linear-regression) | linear regression (from scratch + scikit-learn) | train/test split, scaling, MAE/RMSE/R² | 1 h |
| 3.2 | [Spam detector](02-spam-detector-logistic-regression) | logistic regression + bag of words | text → numbers, precision vs recall | 1 h |

| 3.5 | [Model evaluation playground](05-model-evaluation-playground) | metrics, cross-validation, overfitting | the skill interviewers test most | 1.5 h |
| 3.6 | [Churn predictor, end to end](06-churn-predictor-end-to-end-pipeline) | pipeline → tuning → saved model → API | how ML ships in real companies | 3 h |

```bash
pip install numpy pandas scikit-learn matplotlib joblib fastapi "uvicorn[standard]" httpx pytest
```
That one line covers the whole level. Each project folder also has its own `requirements.txt`, so `pip install -r requirements.txt` inside a folder installs just what that project needs. No API keys and no GPU: every project runs on any laptop in seconds (3.6's training takes about 30 seconds). All data is either generated by the code or built into scikit-learn; only 3.2's optional `--full` mode downloads a dataset.

**How to work through it:** each project README has the same parts: what you'll build, how to run it, the output you should see, a walk through the code, common problems, three "Try this" exercises (with hints and solutions) and "Check yourself" questions. Run it, read the code with the README open, then do the exercises; that's where it sticks.

**Watch alongside:** StatQuest's machine learning playlists explain every model here with pictures: https://www.youtube.com/@statquest/playlists

**Finish line for Level 3:** your churn model answers `POST /predict` with input validation and passing tests (3.6). Then go to [Level 4 · Computer vision](../level-4-computer-vision).
