# 0.2 · Python for AI warm-up

**Goal:** practise the 20% of Python that shows up in 80% of AI code: lists, dicts, functions, classes, list comprehensions, and reading JSON.
**Analogy:** scales and finger exercises before playing a song.

## Run it
```bash
cd level-0-setup/02-python-for-ai-warmup
python warmup.py
```
The file holds 10 tiny exercises. Each has a function with `...` in it and an `assert` that checks your answer.
At first every exercise prints ❌. Fill in the functions until all are ✅.
Stuck? Look in `solutions.py`, but only after trying for 5 minutes.

## What each exercise teaches
| # | Skill | Where you'll use it later |
|---|-------|---------------------------|
| 1-2 | lists, loops, `sum`/`len` | computing averages and loss values |
| 3 | dicts | JSON from APIs, word counts |
| 4 | list comprehensions | data cleaning |
| 5 | `zip` | pairing inputs with labels |
| 6 | sorting with `key=` | ranking search results |
| 7 | classes | `Layer` and `Neuron` classes in Level 2 |
| 8 | `json` | every API in Level 1 |
| 9 | `random` | shuffling training data |
| 10 | f-strings | readable logs |
