# Level 0 · Setup: your workbench

Before building anything, you set up your tools and warm up your Python. Think of it as setting up the kitchen and practising knife skills before cooking a real meal.

| # | Project | You'll be able to |
|---|---------|-------------------|
| 0.1 | [Set up your AI workbench](01-setup-your-ai-workbench) | install Python, Git and VS Code, make a virtual environment, run a script |
| 0.2 | [Python for AI warm-up (10 exercises)](02-python-for-ai-warmup) | use lists, dicts, comprehensions, classes, JSON and f-strings with confidence |

Nothing to install with pip in this level: both projects use plain Python.

**Finish line for Level 0:** `check_setup.py` shows ✅ for Python, the venv and Git, and `warmup.py` says `10/10 done`. Then go to [Level 1 · APIs](../level-1-apis).
