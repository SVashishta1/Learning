# Leeds hub WMS cutover plan (summary)

## Plan
The new warehouse management system goes live on 1 September 2026. Expected impact: up to 2 days of slower scanning.

## Rollback criteria
The plan had no rollback criteria and no extra staffing for the first week.

## Lessons for next time
Future system cutovers should include extra staff for the first week, a backlog threshold that triggers a rollback, and a customer notice in advance.
