# Part 1 · APIs

**An API is a menu for programs.** Your program asks for something ("give me the weather in Paris"), and another program answers with data. Every AI app you'll build later sits behind one.

| # | Project | What you'll have at the end |
|---|---------|-----------------------------|
| 01 | [Your first API](01-your-first-api) | a web address that answers you |
| 02 | [To-do list API](02-todo-list-api) | add, view, finish and delete tasks |
| 03 | [Save to a database](03-api-that-saves-to-a-database) | tasks that survive a restart |
| 04 | [Your code calls another API](04-your-code-calls-another-api) | live weather for any city |
| 05 | [Put your API on the internet](05-put-your-api-on-the-internet) | a link you can open on your phone |

Install once for this part:
```bash
pip install fastapi "uvicorn[standard]" httpx
```
