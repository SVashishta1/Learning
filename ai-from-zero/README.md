# AI from Zero 🌱

**No experience needed.** 32 small projects that take you from "what is Python?" to building chatbots, AI that answers questions about your own documents (RAG), vector databases, and teams of AI agents.

Each project is **one short file** with plain-English comments and a README of the form "run this → see this → try this". The theory is kept to a sentence or two.

| Part | You'll build | Time |
|------|-------------|------|
| [00 · Start here](00-start-here) | install Python, run your first file | 30 min |
| [1 · APIs](part-1-apis) | your own web service, a database, calling other services | 1 week |
| [2 · Machine learning](part-2-machine-learning) | models that predict prices, catch spam, group customers | 1 week |
| [3 · Neural networks](part-3-neural-networks) | a tiny brain that learns, a digit reader, a drawing app | 1–2 weeks |
| [4 · Chatbots](part-4-chatbots) | talk to an AI from code, a chatbot with memory and its own web page | 1 week |
| [5 · RAG & vector databases](part-5-rag-and-vector-databases) | AI that answers from YOUR documents, using Chroma and Postgres | 1–2 weeks |
| [6 · AI agents & teams](part-6-ai-agents-and-teams) | AI that uses tools, AI teams that work together, a final assistant | 1–2 weeks |

**Total: about 6–8 weeks at 1 hour a day.**

**Costs:** everything is free except Parts 4–6, which talk to Claude (Anthropic's AI) and need an API key. A few dollars covers the whole course; see Part 4's README.

**When you finish:** the bigger, deeper projects in [`../ai-engineer-journey`](../ai-engineer-journey) are your next step.
